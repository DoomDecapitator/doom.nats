# 安装与升级

**结论**：解压 → 把 `doom.nats/` 放进存档的 `datapacks/` → `/reload`。升级就是换掉这个文件夹再 `/reload`，你的存档与已生成的生物不受影响。

## 一、安装（三步）

| 步 | 动作 |
|---|---|
| ① | 解压 `dist/doom.nats-v4.30.0.zip`，得到 `doom.nats/` 文件夹 |
| ② | 把整个 `doom.nats/` 放进 `<存档>/datapacks/`；服务器放 `world/datapacks/` |
| ③ | 进世界 `/reload`（新放进世界目录的包**不必退出重进**） |

最终结构长这样：

```
saves/<你的存档>/datapacks/
└── doom.nats/            ← pack.mcmeta 就在这一层
    ├── pack.mcmeta
    ├── data/
    └── ...
```

装好后会看到（聊天栏 / 服务器日志）：

```
[nats] mode/survival —— 已接管自然生成（doMobSpawning=false）
```

没看到就去 `logs/latest.log` 找加载报错。

## 二、为什么它会自动关掉原版刷怪

本包用 `/summon` 造生物，而**原版的刷怪规则不约束 `/summon`**。如果原版自然生成还开着，等于**双份刷怪**（分布、容量、性能三条线同时失控）。所以装载时自动执行 `mode/survival`，把 `gamerule doMobSpawning` 设成 `false`。

只关「自然生成」，**不影响**刷怪笼、结构生成、繁殖、指令召唤、刷怪蛋。

想自己管就用：

```
/function doom.nats:mode/manual     # 以后装载不再自动改 gamerule（状态存在计分板，重载/重进都保留）
/function doom.nats:mode/auto       # 恢复默认：装载时自动接管
/function doom.nats:mode/off        # 退场：静默清掉本包生物 + 把自然生成还给原版
```

## 三、验证装好了

```
/reload
/function doom.nats:debug/env       # 环境快照：人数 / 已加载区块 / 天气 / 阶段 / 维度
/function doom.nats:debug/all       # 全诊断：环境 → 注册表 → 试跑 → 归因直方图 → 消失报告
```

夜里站定等两分钟，再跑一次 `debug/reject_report`，能看到「失败归因」的分布（`reason=0..11`）和成功数：

```
[nats.reject] rej: 0=<抽不到区块> 1=<24格有人> 2=<出128格> 3=<光照档> 4=<落位方块> 5=<全局容量> 6=<本地容量> 7=<spawn cost> spawned=<成功数>
```

## 四、升级

1. 删掉旧的 `datapacks/doom.nats/`
2. 把新 zip 解压出的 `doom.nats/` 放进去（**不要**两个版本叠在一起）
3. `/reload`

> 已经刷出来的生物不会因为换包而消失或变形——它们就是普通生物。
> 你的自定义规则写在 `doom.nats:author` 存储里（见 [[快速上手-在游戏里改规则]]），换包**会**跟着存档保留；但若新版本改了字段语义，请对照 [[规则字段参考]] 复核一遍。

## 五、卸载 / 回滚

```
/function doom.nats:mode/off     # 清场 + 把自然生成还给原版
```

然后删掉 `datapacks/doom.nats`，`/reload`。

> 想让包里的生物也一起消失，必须先跑 `mode/off`（它内置静默清理，**无掉落、无经验**）；直接删文件夹的话，它们会作为普通生物留在世界里。

## 六、注意事项

- **单人别开暂停菜单、别让窗口失焦**——单人暂停会停 tick，刷怪也就不动了。
- 专用服务器 `pause-when-empty-seconds` 默认 60 秒后停 tick，无人时同样不刷。
- 目标环境是 **Minecraft 1.21.6**（`pack_format` 80）；版本不对会加载失败。
- 想核对下载完整性：`dist/SHA256SUMS.txt` 里是**当前发布物**的 sha256（`<sha256>` + 两个空格 + 文件名）。在**仓库根目录**跑 `sha256sum -c dist/SHA256SUMS.txt`；Windows 一行：
  `Get-Content dist/SHA256SUMS.txt | ForEach-Object { $h,$f = $_ -split '\s+'; "$f => " + $(if ((Get-FileHash "dist/$f" -Algorithm SHA256).Hash.ToLower() -eq $h) {'OK'} else {'MISMATCH'}) }`
- **同一存档只放一个变体**：默认变体与实验性变体不要同时装。

> 更细的配置（海平面、容量、节拍、高度带、出生点 24 格排除）见仓库的 [docs/18-配置手册.md](https://github.com/DoomDecapitator/doom.nats/blob/main/docs/18-配置手册.md)。
