# 示例库

**用法**：挑一条，把命令整行贴进聊天栏（需要管理员权限），再 `/function doom.nats:author/show` 确认。全部**立即生效**，改坏了 `/function doom.nats:author/reset` 一键还原。

> 每条都写成「**效果 → 命令 → 注意**」。命令一律是 `data modify storage doom.nats:author ...`。

## 一、按维度刷（主世界 / 下界 / 末地）

**效果**：僵尸只在下界的群系里刷

```
/data modify storage doom.nats:author entityRules."minecraft:zombie".biomeIn set value ["#minecraft:is_nether"]
```

**注意**：`["#minecraft:is_nether"]` 是群系标签，不用把几十个群系列出来。反过来用 `biomeNot` 排除。

**效果**：末地额外加一种"末影巡逻兵"（只在末地城那个群系、带紫色名字）

```
/data modify storage doom.nats:author entries append value {id:"end_patrol",biome:"minecraft:the_end",category:"monster",mob:"minecraft:enderman",weight:30,min:2,max:4,nbt:"{CustomName:'{...}'}"}
```

**注意**：`nbt` 里放的是 JSON 字符串，引号要转义；本页末的"带 NBT 的特产"有更简单抄的写法。

**效果**：发光鱿鱼不再刷在主世界（下界 / 末地照旧）

```
/data modify storage doom.nats:author entityRules."minecraft:glow_squid".biomeNot set value ["#minecraft:is_overworld"]
```

## 二、落位面（原版根本站不住的地方）

**效果**：僵尸刷在树叶上（树冠层生态）

```
/data modify storage doom.nats:author entityRules."minecraft:zombie".belowAny set value ["#minecraft:leaves"]
```

**效果**：极地：浮冰 / 蓝冰上也刷北极熊

```
/data modify storage doom.nats:author entityRules."minecraft:polar_bear".belowAny set value ["minecraft:blue_ice","minecraft:packed_ice"]
```

**效果**：下界：岩浆块与黑曜石上也刷僵尸猪灵

```
/data modify storage doom.nats:author entityRules."minecraft:zombified_piglin".belowAny set value ["minecraft:magma_block","minecraft:obsidian"]
```

**效果**：发光鱿鱼上陆地（"修 bug"就是这么修的）

```
/data modify storage doom.nats:author entityRules."minecraft:glow_squid".place set value "ground"
/data modify storage doom.nats:author entityRules."minecraft:glow_squid".light set value "dark"
```

**注意**：一条命令只改一个键；`belowAny` 是**追加**"能站的地方"，不是替换原版能站的所有方块。`belowAny` 里写的是**方块标签**（`#minecraft:leaves`）或具体方块 id（`minecraft:oak_leaves`）——`minecraft:leaves` 是标签名、不是方块 id，漏了 `#` 这条就不生效。
**注意**：发光鱿鱼还差一道深度门（原版 y ≤ 海平面-33，规则级开关）——运行时刻去不掉；上面两条能让它落位/光照变陆生，但要真在陆地上刷出来得构建期改 `rules/`（`"ySea": null`）。

## 三、光照（地下专属 / 白天限定）

**效果**：流浪者（stray）只刷在亮度 ≤ 3 的地方——地下洞窟专属

```
/data modify storage doom.nats:author entityRules."minecraft:stray".lightMax set value 3
```

**效果**：羊只刷在亮度 ≥ 9 的地方——白天草原动物

```
/data modify storage doom.nats:author entityRules."minecraft:sheep".lightMin set value 9
```

**注意**：光照是**近似**的（游戏里只有 5 档区间能判），所以别拿它跟原版逐格对；连续数值做不到（见 [[已知限制]]）。

## 四、高度

**效果**：山羊只刷在 Y 120 以上（高原 / 山地专用）

```
/data modify storage doom.nats:author entityRules."minecraft:goat".yMin set value 120
```

**效果**：蠹虫只刷在 Y 10 以下（深洞专属）

```
/data modify storage doom.nats:author entityRules."minecraft:silverfish".yMax set value 10
```

**注意**：`yMin` / `yMax` 是**闭区间**，可以只写一个。

## 五、天气 / 情形

**效果**：雷暴 + 深海 + 海面以下，才刷带三叉戟的溺尸

```
/data modify storage doom.nats:author entries append value {id:"storm_drowned",biome:"#minecraft:is_deep_ocean",category:"monster",mob:"minecraft:drowned",weight:50,when:{thundering:true,yMax:40},nbt:"{HandItems:[{id:\"minecraft:trident\",Count:1b},{}]}"}
```

**效果**：下雨才出现的史莱姆（沼泽）

```
/data modify storage doom.nats:author entries append value {id:"rain_slime",biome:"#minecraft:is_swamp",category:"monster",mob:"minecraft:slime",weight:20,when:{raining:true}}
```

**注意**：`when` 里的多个条件是 **AND**；条件不成立时这条根本不进候选池，所以它不会挤掉原版物种。

## 六、数量与规模

**效果**：越深越挤——僵尸一组 4~6 只，地表只出 1 只

```
/data modify storage doom.nats:author counts.groupByY."minecraft:zombie" set value [{yMax:0,min:4,max:6},{yMin:1,min:1,max:1}]
```

**效果**：地下的怪物总容量翻倍（全局 200 / 每人 140），地表维持原样

```
/data modify storage doom.nats:author counts.capByY.monster set value [{yMax:0,max:200,localMax:140},{yMin:1,max:70,localMax:70}]
```

**效果**：一次多出几只（"蝗灾"感）—— 蜘蛛一次 4 只
（运行时刻改不了"簇上限"：原版多数生物 = 4；`cluster` 是构建期字段，见 [[规则字段参考]]）

```
/data modify storage doom.nats:author counts.groupByY."minecraft:spider" set value [{min:4,max:4}]
```

**注意**：Y 段最多 8 段；容量是**上限**，实际到不到得了还看区块数与玩家数。

## 七、带 NBT 的"特产"（装备 / 名字 / 药水 / 乘客）

**效果**：同一个僵尸，两种地域变体（沙漠穿皮革头、雪原照旧）

```
/data modify storage doom.nats:author entries append value {id:"desert_zombie",biome:"minecraft:desert",category:"monster",mob:"minecraft:zombie",weight:10,nbt:"{equipment:{head:{id:\"minecraft:leather_helmet\",count:1}}}"}
```

**效果**：骑着鸡、静音、无重力（"漂着的鸡骑士"，只在雷暴的森林）

```
/data modify storage doom.nats:author entries append value {id:"ghost_rider",biome:"#minecraft:is_forest",category:"monster",mob:"minecraft:zombie",weight:5,when:{thundering:true},nbt:"{Silent:1b,NoGravity:1b,Passengers:[{id:\"minecraft:chicken\"}]}"}
```

**效果**：出生就带永久速度效果

```
/data modify storage doom.nats:author entries append value {id:"swift_zombie",biome:"minecraft:plains",category:"monster",mob:"minecraft:zombie",weight:5,nbt:"{active_effects:[{id:\"minecraft:speed\",amplifier:1b,duration:-1,show_particles:1b}]}"}
```

**注意**：1.21.5+ 的装备要写成 `equipment:{}`；NBT 字符串里的引号必须转义，最容易在这一步翻车。

## 八、看 / 撤销 / 分享

```
/function doom.nats:author/show      当前所有覆盖
/function doom.nats:author/export    打成一行命令，能发给别人
/function doom.nats:author/reset     全部回到原版
```

## 九、实验性专属（世界需开启对应实验性玩法）

**效果**：附近有狼才刷羊（"狼群附近"的生态感）

```
/data modify storage doom.nats:author entries append value {id:"wolf_sheep",biome:"#minecraft:is_forest",category:"creature",mob:"minecraft:sheep",weight:10,when:{near:{type:"minecraft:wolf",radius:24,min:1}}}
```

**效果**：生成时放一段演出——粒子 + 雷声 + 播报

```
/data modify storage doom.nats:author entries append value {id:"thunder_king",biome:"#minecraft:is_deep_ocean",category:"monster",mob:"minecraft:zombie",weight:60,when:{thundering:true},on_spawn:1b}
```

**注意**：这两条**只在实验性变体** `doom.nats-v4x-experimental-v4.28.zip` 里，而且世界必须在创建时开启对应实验性玩法。见 [[实验性变体-v4x]]。
**注意**：`on_spawn` 不是内联命令串 —— 写 `on_spawn:1b` 只是打开钩子，演出命令要另建函数文件 `data/doom.nats/function/exp/on_spawn/<条目 id>.mcfunction`（`@s` = 刚生成的实体）。
