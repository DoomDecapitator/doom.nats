# 版本与验收

**结论**：当前发布 **v4.25（Beta / 预发布）**，目标环境 **Minecraft 1.21.6**（`pack_format` 80）。每次发版都过**四道门**，数字留档在开发仓库的 `reports/`。

## 一、四道门是什么

| 门 | 查什么 | 命令（都在开发仓库跑） | 最近结果 |
|---|---|---|---|
| ① 静态 | 生成器无漂移 + lint L1–L14 + 引用闭包 | `node tools/check_static.mjs` | **0 error / 2 warning**（< 2 秒，CI 已接） |
| ② 加载期 | 装机 + `/reload`，只看本轮 `Failed to load function` | 内建在 `mcauto` / `regress` | **0** |
| ③ 真机断言 | 逐实体规则、动物、持久化、维度、多机器人、物种混合、要塞端到端 | `_work/verify_*.mjs` | `rules 16/0` · `animals 6/0` · `persist 10/0` · `dims 13/0` · `multibot 4/0` · `species_mix 9/0` · `dim_att 6/0` · `fortress_e2e 3/0`（表外 0/24 = 0.0%）· `e6_generic 7/0` |
| ④ 一键回归 | 静态 → 离线 → 真机 → 生存开关 | `node tools/regress.mjs --reuse --minutes 1 --curve 1` | **16 PASS / 0 FAIL** |

> 记法：`16/0` = 16 条通过 / 0 条失败。门 ③ 的断言脚本带 RCON 端口参数，可指到隔离实例跑，不影响正式服。

## 二、容量与性能（本机实测）

| 指标 | 实测 |
|---|---|
| 稳态怪物数 | **71.7**（cap 70，峰值 77）—— 容量链真的在管 |
| mspt | 均值 **5.29** / 峰值 5.70（预算 50） |
| 全清后回满 | 2 秒内 70 → 26，约 **6 秒**回到 70 |
| 吞吐上限来源 | **不是性能，是原版 `maxCommandChainLength`（默认 65536 ≈ 10 次尝试/tick）** |
| 抬到 1,000,000 后 | batch 40 → 9.7 ms；160 → 24.1 ms；400 → **50.9 ms（超预算）** |

**建议**：mspt 想守在 30 ms 以内 ⇒ `$eff.batch` 不超过 **200**。自定义地图要更高密度，优先抬 `maxCommandChainLength`，别把帧预算吃光。

## 三、版本线（玩家可见）

| 版本 | 一句话 |
|---|---|
| **v4.25** | 自定义外观桥接（实验性）：真实体当内核 + 骨架当外观，位移误差 0.0000 格，容量只数内核 —— **但源码在（`src/tools/gen_exp_aj.mjs`）、未随本版成品发布**：需自备非空 `rules/rigs.json`（样例 `src/rules/examples/aj/rigs.json`）并 `DOOM_EXP=1` 重跑生成器才会产出；本仓 `src/rules/rigs.json` 就是 `{}`，成品 zip 里 `exp/aj` 条目为 0（上列数字来自非空 rigs 的实验构建） |
| v4.24 | 运行时刻作者层：改 `doom.nats:author` 即刻生效，不用重装包；非原版能力单独放进实验性变体 |
| v4.23 | 作者规则层：逐实体规则 / 条件条目 / 数量曲线（**默认全部为空 = 原版行为**） |
| v4.22 及更早 | 消失层最近玩家量词 bug、跨维度容量、水中溺尸、组数据层、逐实体光照等成片修复 |

同批修复的玩家可见问题：主世界四类水生生物**全局容量判定恒读 0**（容量门形同不存在）；实验性变体因一个孤儿文件导致整函数加载失败；`data merge` 递归把上一条 NBT 粘到下一只；1.21.5+ 装备 NBT 应为 `equipment:{}`。

完整逐版本条目与数字见仓库的 [CHANGELOG.md](https://github.com/DoomDecapitator/doom.nats/blob/main/CHANGELOG.md)。
