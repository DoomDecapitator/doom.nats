# 规则字段参考

**结论**：能改的东西分三大块——**逐实体规则**（某个生物怎么刷）、**追加条目**（什么条件下多刷什么）、**数量曲线**（一次几只 / 这一类能有多少）。下面按"落位面 / 光照 / 高度 / 群系 / 天气 / 数量"六个维度列全。

> **字段表以开发仓库的 `rules/README.md` 为准**（[查看](https://github.com/私有开发仓库/blob/main/doom.nats/rules/README.md)）；本页是玩家速查版，若两者不一致，以那一份为准。
> 改法一律是往存储 `doom.nats:author` 里写（见 [[快速上手-在游戏里改规则]]），改完下一拍生效。

## 一、逐实体规则 `entityRules."<实体 id>"`

| 键 | 取值 | 作用 | 例子 |
|---|---|---|---|
| `belowAny` | 方块标签数组 | **额外算"能站的地方"** | `["#minecraft:leaves"]` ⇒ 僵尸能刷在树叶上（方块标签别漏 `#`） |
| `place` | `ground` / `any` / `water` / `water_surface` / `below_tag` / `lava` | 落位类型（要不要地面、要不要在水里） | 发光鱿鱼改 `ground` ⇒ 上陆地 |
| `light` | `none` / `dark` / `bright` / `bat` / `slime` / `glow` / `bl8` | 光照档 | `dark` ⇒ 只在暗处刷 |
| `lightMax` / `lightMin` | 0–15 | **比档位更细**的亮度上下限 | `lightMax:7` ⇒ 只在天黑后刷 |
| `yMin` / `yMax` | 整数（闭区间） | 只在某个高度刷 | `yMin:-64,yMax:0` ⇒ 只在地下 |
| `biomeIn` / `biomeNot` | 群系 id 数组，或 `["#标签"]` | 只在 / 不在这些群系 | `["#minecraft:is_deep_ocean"]` |
| `weather` | `thunder` / `rain` / `clear` | 只在某种天气 | `thunder` ⇒ 雷暴限定 |
| `persist` | `true` | 生成即永不消失（做"地标怪"） | — |

> **只能构建期改的键**（写进 storage 不会生效）：`tag`（`below_tag` 用哪个标签）· `cluster` · `coins` · `sky` `deep` `river98` `d64` `noPlayer5` `ySea` `yTurtle` `lavaToAir` `noSky` `belowSurface` `notWart` `moreDrowned`。
> 它们是源码级/规则级开关：比如发光鱿鱼的深度门（y ≤ 海平面-33）按规则号判，运行时刻改 `place` 绕不过去 —— 要动它们在构建期改 `rules/` 后重新生成。

## 二、追加条目 `entries[]`（一条 = "什么条件下多刷什么"）

| 字段 | 说明 |
|---|---|
| `id` / `mob` / `category` | 名字 / 实体 id / 类别（`monster` `creature` `ambient` `water_creature` `water_ambient` `underground_water_creature` `axolotls`） |
| `biome` | 群系 id 或 `#标签`（**单数**；要多个群系就加多条） |
| `weight` | 与原有物种**同一个池子**竞争；条件不成立时它根本不进池 |
| `min` / `max` | 一次生几只（还受原版"簇上限"约束，多数生物 ≤ 4） |
| `nbt` | 自定义 NBT：装备、名字、属性、药水效果、乘客…（1.21.5+ 装备写成 `equipment:{}`） |
| `when` | `thundering` `raining` `yMin` `yMax` `lightMax` `lightMin`（多个条件全部 AND） |

> 构建期条目（`rules/entries.json`）另有 `biomes`（多群系数组）/ `group:[最少,最多]` / 条目级 `place`·`light`·`tag`·`cluster` 覆盖 / `groupByY` —— 那是另一套写法，写进 storage 不生效。

## 三、数量曲线 `counts`

| 键 | 作用 |
|---|---|
| `groupByY."<实体>"` | `[{yMin?,yMax?,min,max}]`：**一次生几只**按高度分段 |
| `capByY."<类别>"` | `[{yMin?,yMax?,max,localMax}]`：**这类生物的总容量 / 每玩家容量**按高度分段 |

## 四、硬上限（超出不生效）

条目 **8** 条 · Y 段 **8** 段 · 落位面标签 **8** 个 · 群系列表各 **4** 条。

## 五、六个维度的速查

| 维度 | 用哪些键 |
|---|---|
| 落位面 | `belowAny` · `place` · `tag`（+ 全局方块标签见下） |
| 光照 | `light`（档） · `lightMax` / `lightMin`（细） |
| 高度 | `yMin` / `yMax` · `counts.groupByY` · `counts.capByY` |
| 群系 | `biomeIn` / `biomeNot` |
| 天气 / 时间 | `weather` · `when.thundering` / `when.raining` |
| 数量 | `weight` · `group` · `counts.*` |

## 六、标签接口（作者/整合包最常用）

| 东西 | 作用 |
|---|---|
| `#doom.nats:standable` / `#doom.nats:full_collision` | "什么算能站的地面" |
| `#doom.nats:spawnable_at` / `#doom.nats:narrow_partial` | "什么算空位 / 窄条可通过" |
| `#doom.nats:water_fluid` | 什么算"水"（含水草 / 海带 / 气泡柱） |
| `doom.nats.persistent` 实体标签 | 免疫本包的清理与消失层（原版消失逻辑仍适用） |
| `PersistenceRequired:1b` | 原版语义：永不消失 |
| `#doom.nats:monster` 等类别标签 | 按类别筛选 / 统计，如 `@e[type=#doom.nats:monster]` |

## 七、运行时旋钮（不是规则，是"强度"）

海平面、每类容量、消失距离、刷怪节拍、批处理量、出生点 24 格排除、持久化、和平难度开关……这些走配置层：

```
data merge storage doom.nats:config {cap:{monster:70}, persist:0, border:{centerX:0,centerZ:0,size:0}}
function doom.nats:cfg/apply
```

完整键清单与取值范围见仓库的 [docs/18-配置手册.md](https://github.com/DoomDecapitator/doom.nats/blob/main/docs/18-配置手册.md)。
