# 极端 E5 · 水生落位：方块判定 vs 原版流体语义（2026-09-29）

**结论**：找到并修掉一处**成片砍掉水生落位点**的偏差 —— 本包的水生落位判定用**方块**，原版用 **fluid state**。
海草/海带/气泡柱的流体**就是水**，改前这些格子全被误拒（海草在海底铺得很广 ⇒ 系统性压低溺尸/鱼/鱿鱼的落位面）。

## 修复（生成器改 → 产物重生成 → 双端 reload）

1. 新增方块标签 `doom.nats:water_fluid` = `water / seagrass / tall_seagrass / kelp / kelp_plant / bubble_column`（流体为水的自然方块）；
2. `check/block`：`place 2`（水中）与 `place 3`（水面窗口）的**本体/下方/上方**三处判定全部改用它；
3. `check/entity`：溺尸「脚下必须是水」那条改用它（原来只认 `water` + `bubble_column`）；
4. 反向补齐：`place 0/1/4`（陆生）对水草格**也要拒**（原版 `isValidEmptySpawnBlock`：流体非空 ⇒ 拒），原来只拒 `water`。

产物共 13 处判定落到该标签：`check/block` 12 处（place 0/1/2/3/4）+ `check/entity` 1 处。静态门 **0 error / 2 warning（既有）**。
