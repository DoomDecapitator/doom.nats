## 四·补 · 采集链路的两个 bug（v4.1 已修，2026-09-27）

这一轮的教训：**代码写完了，但采集链路自己坏了，实测数据进不了报告**。两处都在 `tools/collect.mjs`：

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| ① | 直方图小节**永远**为空 | `m.t` 里写的是 `/reason=(d+)/` —— 转义被吃掉，`\d` 变成字面 `d` | 改成正则字面量 `([0-9]+)`，并兼容快照行 |
| ② | `[nats.env]` / `[nats.reject]` / `[nats.light]` / `[dryrun]` **一条都采不到** | 标记行筛选是 `/\[(test|check|dump|nats|doom\.log)\]/`，只认整词 `[nats]` | 允许标签后带后缀：`[^\]]*` |
| ③ | 数值仍解析不到 | 客户端把 tellraw 写进日志时插入 `§` 颜色码（如 `0=§f12`） | 解析前 `stripSec()` 剥掉 `§.` |

生成器侧同步修了三处"只有标签没有值"：

| # | 症状 | 修法 |
|---|---|---|
| ④ | `debug/reject_report` 只打 label、**不打数值**就清零 | 改为先打两行机器可读快照再清零：`[nats.reject] rej: 0=… 7=… spawned=…` 与 `[nats.light] tier: 0=… 15=…` |
| ⑤ | `$spawned` 从没被加过（`add $spawned 0`） | 成功路径改 `add $spawned 1` |
| ⑥ | 归因只有 0..5，`rej.6`/`rej.7`（本地容量 / spawn cost）没打印 | 补齐 0..7 全部与清零 |
| ⑦ | 光照失败**分不清是哪一档** | 新增 `debug/light_fail`（宏，`tier` 参数）：`$lit.<tier> += 1` 后仍走 `check/fail {reason:3}`，不改生成语义 |

**红→绿证据**：同一份构造日志，改动前 `collect.mjs` 产出空小节；改动后产出完整的
8 行 reason 直方图 + 5 行光照档位表 + `[nats.env]` 快照。构造日志只用于验证管线，
其数值**不是**实测结果（验证后已删除生成的报告）。

## 四·补二 · v4.2：真机第一次跑就暴露的 5 个「静默失效」（2026-09-27 19:18）

用户在 19:18 用 v4.1 跑了一次 `debug/all`，日志直接给出 71 条 `Failed to load function`。
逐条对源码后确认，这类问题**静态检查（lint/closure/drift）全都看不见**，只有真机加载器/解析器才会拒绝。
同一批问题随后由无头解释器（`tools/sim_v4.mjs`）独立复现，形成两条互相印证的证据链。

| # | 症状（真机） | 根因 | 修法 |
|---|---|---|---|
| 1 | 整包**一次都不刷怪**、且毫无报错 | 9 处宏占位符写成 `${x}`，Minecraft 只认 `$(x)`；`spawn/at` 的 `positioned ${x} ${y} ${z}` 解析失败 ⇒ 整条生成链断在那一步 | 生成器里全部改回 `$(...)`（15 处）；lint 新增 **L7** 规则：宏行出现 `${...}` 直接 ERROR |
| 2 | 65 个 `mob/biome/*` 加载失败（选物种层全废） | `data modify storage X set value {…}` **缺少 path 参数**（1.21.6 不接受无 path 的 storage 写入） | 改为 `data merge storage X {…}`（769 行） |
| 3 | 谓词 `spawn/empty_here` 加载失败 | `location_check.block.blocks[]` **不接受 `#tag` 引用**（报 `Not a valid resource location: #minecraft:replaceable`） | 该列表只列显式方块 id（标签引用只能出现在 `tags/block/*.json`） |
| 4 | `$pos.ok` 闸门恒为 0 ⇒ `spawn/at` 永不执行 | `pos/hit` 只写了 storage 的 `ok`，从没写 scoreboard 的 `$pos.ok` | `pos/hit` 末尾补 `scoreboard players set $pos.ok doom.nats 1` |
| 5 | 归因行打印成 `0= 1= 2=` 空值 | 从未出现过的计分板条目在 tellraw 的 score 组件里渲染为空串 | `reject_report` 打印前先 `scoreboard players add $<name> doom.nats 0` 建条目（14 条），再打数值、最后清零 |

**解释器侧同步修好 4 个缺陷**（否则 sim 无法作为证据）：
`data get storage`、内联宏参数 `function ns:f {a:1}`、`tellraw` 渲染与收集、`execute if biome/dimension`、
`weather_check` 谓词、`time query daytime`；以及**选择器重复键被覆盖**（`tag=A,tag=!B` 只生效最后一个，
曾把玩家当成 mob 选中并 `kill @s`）。

**新增离线验证入口**：`node tools/sim_v4.mjs [tick]` —— 把 v4 本体跑进无头解释器，
产出与真机同格式的 `[check]` / `[nats.reject]` / `[nats.env]` 行，可直接喂给 `collect.mjs`。
三场景：晴夜 / 雨夜 / 雷暴夜，断言 cap 公式、情形切换（雨→period 3·max 90；雷暴→2·100）、
归因链活性、落位归因。**它不能替代真机**（合成地形/光照/方块都是假的），但能在离线阶段抓住第 1、4、5 类静默失效。
