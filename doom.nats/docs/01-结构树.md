# suso.nats 标准化结构树

- **数据包**：`suso.nats`（Suso's utility datapack for fake natural spawns）
- **上游**：<https://github.com/5uso/Artificial-Natspawns>
- **来源**：`<本机路径>  Ragecraft IV - by heliceo   Suso - v1.1.0.zip`
  → `[1.20.1] Ragecraft IV - by heliceo & Suso - v1.1.0/datapacks/suso.nats/`
- **本仓库副本**：`doom.nats/original/suso.nats/`（125 文件，约 0.1 MB）
- **声明 pack_format**：`13`（地图本体 `rc4` 为 `15`；旧于地图，加载时仅告警）
- **规模**：102 `.mcfunction` + 22 `.json` + 1 `.mcmeta` = 125 文件

## 一、物理目录树（原样）

```
suso.nats/
├── pack.mcmeta                                   pack_format 13
└── data/
    ├── minecraft/tags/functions/                 ← 钩子层（2）
    │   ├── load.json                             → suso.nats:setup
    │   └── tick.json                             → suso.nats:main
    └── suso.nats/
        ├── functions/                            主命名空间（102）
        │   ├── setup.mcfunction                   载入初始化
        │   ├── main.mcfunction                    tick 节流入口
        │   ├── check.mcfunction                   实体数上限闸门
        │   ├── repeat.mcfunction                  尝试次数循环
        │   ├── do.mcfunction                      单次尝试：朝向 + 距离
        │   ├── try.mcfunction                     浮空/地面分流
        │   ├── fall.mcfunction                    地面下落探测
        │   ├── rng/                              （3）
        │   │   ├── seed.mcfunction                播种
        │   │   ├── seed_pt2.mcfunction            取 AEC 的 UUID[0] 作种子
        │   │   └── lcg.mcfunction                 glibc LCG 一步
        │   ├── pos_search/                       （63）二分查找树
        │   │   ├── s.mcfunction                   L1
        │   │   ├── s0 / s1                        L2
        │   │   ├── s00 … s11                      L3
        │   │   ├── s000 … s111                    L4
        │   │   ├── s0000 … s1111                  L5
        │   │   └── s00000 … s11111                L6 = 叶（32），唯一含 positioned
        │   ├── spawn/
        │   │   ├── float/                        （3）
        │   │   │   ├── check.mcfunction           #free 判定
        │   │   │   ├── do.mcfunction              （全注释：禁用）
        │   │   │   └── water/do.mcfunction        召唤 axolotl
        │   │   └── ground/                       （26）
        │   │       ├── check.mcfunction           2 格净空 + 17 格内无玩家
        │   │       ├── do.mcfunction              亮度分流 → 生成 ns_ground 标记实体
        │   │       ├── dark.mcfunction            暗侧：贴 ns_ground_dark 标记
        │   │       ├── light.mcfunction           亮侧：贴 ns_ground_light 标记
        │   │       ├── ns_ground.mcfunction       标记实体派发 + 自毁
        │   │       ├── ns_ground_dark.mcfunction  17 条生物群系谓词派发
        │   │       ├── ns_ground_light.mcfunction 1 条（lush_caves）
        │   │       ├── dark_<biome>.mcfunction    18 个暗侧刷怪表
        │   │       └── light_lush_caves.mcfunction 1 个亮侧刷怪表
        ├── predicates/                           （18）
        │   ├── dark.json                         location_check → light 0..3
        │   └── <biome>.json × 17                 entity_properties → location.biome
        └── tags/blocks/                          （2）
            ├── solid.json                        336 项（可站立）
            └── free.json                         183 项（可穿过）
```

## 二、语义分层（标准化模型）

| 层 | 名称 | 构成 | 职责 |
|---|---|---|---|
| **L0** | 钩子层 | `minecraft/tags/functions/{load,tick}.json` | 挂载 `setup` / `main` |
| **L1** | 调度层 | `setup` `main` `check` `repeat` | 节流、随机选玩家、实体数封顶、尝试循环 |
| **L2** | 随机层 | `rng/{seed,seed_pt2,lcg}` | glibc LCG，种子来自 AEC 的 `UUID[0]` |
| **L3** | 定位层 | `do` + `pos_search/*`(63) | 掷出偏航/俯仰/距离，二分树定位到候选点 |
| **L4** | 判定层 | `try` `fall` `spawn/*/check` | 浮空 vs 地面分流、下落探测、净空与玩家距离 |
| **L5** | 派发层 | `spawn/ground/{dark,light}` `ns_ground*` | 亮度分流 → 标记实体 → 生物群系谓词派发 |
| **L6** | 内容层 | `dark_<biome>`×18 `light_lush_caves` | 各生物群系刷怪表（权重、NBT、装备） |
| **D** | 数据层 | `tags/blocks/{solid,free}` `predicates/*` | 方块判定与生物群系/亮度判定 |

## 三、运行时调用图

```
tick ──► main                       # 每 tick
          └─($t % $period == 0 && $enable == 1)
             at @r[非旁观, 非 suso.nats.no]
             └─► check              # 128 格内 suso.nats.count 实体数
                   └─(count < $cap)
                      └─► repeat        # $k = $repeat 次
                            └─► do      # 单次尝试
                                 ├─ rng/lcg → rot[0]  偏航 0.00–359.99°
                                 ├─ rng/lcg×3 → rot[1] 俯仰（偏向 0°）
                                 ├─ data modify entity <marker-UUID> Rotation
                                 ├─ rng/lcg → $s = 0..31
                                 └─ rotated as <marker-UUID>
                                    └─► pos_search/s   # 5 层二分 → 叶
                                          └─ positioned ^ ^ ^D  align xyz  ~.5
                                             └─► try
                                                  ├─5%─► spawn/float/check
                                                  │       ├─ #free → (空)
                                                  │       └─ water → axolotl
                                                  └─95%► fall          # 最多 $i=10 格下落
                                                          └─► spawn/ground/check
                                                               └─► spawn/ground/do
                                                                    ├─ predicate dark → dark   ┐
                                                                    └─ 否则          → light  ┘
                                                                         └─ summon marker{ns_ground*}
                                                                            └─► ns_ground
                                                                                 ├─ ns_ground_dark  → 17 谓词分支
                                                                                 │    └─ dark_<biome> → summon <mob>{...,Tags:["suso.nats.count"]}
                                                                                 ├─ ns_ground_light → light_lush_caves
                                                                                 └─ kill @s
```

`pos_search` 二分树：`$s∈[0,31]` → 32 叶，**距离 = 27 + 3·$s**，即 27…120 格、步长 3。

## 四、关键常量与可调参数

| 计分板玩家 | 目标 | 默认 | 含义 | 设置位置 |
|---|---|---|---|---|
| `$period` | `suso.nats` | 5 | 每 N tick 触发一次 | `setup`（可外部覆盖） |
| `$repeat` | `suso.nats` | 10 | 每次触发的尝试次数 | `setup` |
| `$cap` | `suso.nats` | 70 | 128 格内实体数上限 | `setup`；**地图会改写**（14 / 25 / 70） |
| `$enable` | `suso.nats` | **未设置 → 0** | 总开关 | ⚠️ **本包及同捆 7 包均无写入点** |
| `#32` `#135` `#1000` `#36000` | `suso.nats` | — | 取模常数 | `setup` |
| `#rng` `#rng.mult` | `suso.nats` | — | LCG 状态与乘子 | `setup` / `rng/seed` |

- 哨兵实体：`marker`，坐标 `29999999 100 27115050`，UUID `50502711-0-0-4-0`
  （`[I;1347430161,0,262144,0]`，Java 宽松 UUID 解析），由 `forceload` 保活。
- 播种实体：`area_effect_cloud`，同坐标，标签 `suso.nats_rng`。
- 生成实体统一带 `Tags:["suso.nats.count"]`，仅用于计数，**无回收机制**。

## 五、外部依赖

| 依赖 | 位置 | 说明 |
|---|---|---|
| `general:dimension_abyss` | `rc4` 包 `data/general/predicates/dimension_abyss.json` | `dark_the_void` 使用；判定 `location.dimension = minecraft:abyss`（地图自定义维度） |

## 六、已发现的缺陷（移植前基线）

| # | 严重度 | 位置 | 问题 |
|---|---|---|---|
| B1 | **致命** | `ns_ground_dark.mcfunction` | 调用 `suso.nats:spawn/ground/basalt_deltas`，实际文件名为 `dark_basalt_deltas` → 悬空引用 |
| B2 | **致命** | `tags/blocks/free.json` | 含 `minecraft:grass`（1.20.3 起更名 `short_grass`） |
| B3 | 高 | `main.mcfunction` | `$enable` 全工程无写入点，系统默认永不运行 |
| B4 | 中 | `dark_lush_caves.mcfunction` | RNG 区间 `1..250` 与 `250..600` 在 250 重叠 |
| B5 | 中 | `spawn/ground/do.mcfunction` | 每个候选点 `summon marker` → 派发 → `kill`，无谓实体开销 |
| B6 | 低 | `pack.mcmeta` | `pack_format: 13` 低于地图本体 `15` |
| B7 | 低 | `spawn/float/do.mcfunction` | 整文件被注释，浮空地面刷怪为死代码 |
| B8 | 低 | `dark_the_void.mcfunction` | `DeathLootTable:"none"`（应为 `minecraft:empty`） |
| B9 | 低 | 全局 | `pos_search` 用 63 文件表达 `D = 27 + 3·s` 的算术式 |
