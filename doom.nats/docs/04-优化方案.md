# suso.nats v2 优化方案（面向 1.21.6 / 1.20.2+ 新能力）

- **日期**：2026-09-18
- **目标**：在完成 1.21.6 移植的同时，用 1.20.2 以来新增的命令能力重构控制流，**消灭全部"假实体"**，并以**无头静默计算**验证行为等价。

---

## 一、可用新能力（已从 1.21.6 jar 取证）

| 能力 | 引入版本 | jar 证据（字面量所在类） | 本方案用途 |
|---|---|---|---|
| **函数宏** `$` 行 + `function <id> with <storage\|entity\|block>` | 1.20.2 | `with` ∈ `yz,aon,aot` | ① 63 文件二分树 → 1 文件；② 直接注入 `rotated $(yaw) $(pitch)` |
| **`return` / `execute if function`** | 1.20.2 | `return` ∈ `app`（`app` 同含 `run`） | 把判定写成"纯函数"，用返回值替代标记实体 |
| **`/random value\|roll\|sequence\|reset`** | 1.20.2 | `random` ∈ `apm`（同含 `roll`,`sequence`,`reset`） | 播种不再需要实体；`roll` 可做加权表 |
| **`/tick freeze\|sprint\|rate\|step`** | 1.20.3 | `tick` ∈ `aqp`（同含 `sprint`,`freeze`,`rate`,`step`,`unfreeze`） | **实例化验证**：冻结 + 快进，确定性观察刷怪 |
| **`/attribute ... base set` / `modifier add`** | 1.20.5 | `attribute` ∈ `ann`（同含 `modifier`,`get`） | 兜底：NBT 属性失败时可后置设置 |
| **`/item replace entity <slot> with <item>[组件]`** | 1.20.5 | `item` ∈ `anu`（同含 `replace`） | 兜底：装备可用组件语法后置设置 |
| **`/enchant`** | 1.21 | `enchant` ∈ `aoh` | 兜底：附魔后置 |
| **`locator_bar_icon` 实体字段** | 1.21.6 | `locator_bar_icon` ∈ `cam`（LivingEntity 编解码器） | 可选：自定义怪在定位条上可见 |
| **`/waypoint` `/dialog`** | 1.21.6 | `waypoint` ∈ `aqw`；`dialog` ∈ `aao` | 不用 |

> 注：`macro` 本身不作为字面量出现——宏是**函数加载器**对 `$` 行前缀的处理，配合 `function ... with` 使用，佐证即 `with` 字面量。

## 二、"舍弃实体"清单

`original` 包一共使用了 **4 类非产物实体**，全部可消灭：

| # | 实体 | 用途 | 出现位置 | v2 替代 |
|---|---|---|---|---|
| **E1** | `marker`（哨兵，`29999999 100 27115050`，UUID `50502711-0-0-4-0`） | 仅作 `Rotation` 的载体，供 `rotated as <uuid>` 读取 | `setup` 1 次 + `do` 每候选 1 次 `data modify entity` | **宏**：`$execute rotated $(yaw) $(pitch) positioned ^ ^ ^$(dist) …` |
| **E2** | `area_effect_cloud`（同坐标，标签 `suso.nats_rng`） | 用 `UUID[0]` 给 LCG 播种 | `rng/seed` + `rng/seed_pt2` | **`/random value 0..2147483647`** 存入 `#rng` 计分板 |
| **E3** | `marker{Tag:ns_ground}`（暗/亮派发） | 把执行位置"实体化"，让 `entity_properties{entity:"this"}` 有实体可判 | `spawn/ground/{do,dark,light,ns_ground}` | **谓词改 `location_check`**（用命令位置而非实体）+ `execute if predicate` 直接派发 |
| **E4** | `marker{Tag:ns_ground_dark/light}`（生物群系派发） | 同上，17 条生物群系判定 | `ns_ground_dark` / `ns_ground_light` | 同上 |
| ✅ | `suso.nats.count` 标记的**产物怪** | 产物 + 128 格封顶计数 | 18 张刷怪表 | **保留**（这是数据包的产出本身） |

**连带删除**：`forceload add 29999999 27115050`、30M 坐标区块依赖、`kill @s` 自毁、`pos_search/` 63 个文件。

**E3/E4 的关键依据**：原版 `LocationCheck` 条件优先使用 `LootContextParams.ORIGIN`（即**命令位置**），无实体时也成立；而 `EntityHasProperty`（`entity_properties`）需要 `THIS_ENTITY`，这就是作者被迫 summon marker 的根因。
把 17 个 `entity_properties{location.biome}` 改写成 `location_check{predicate.biome}` 后，`execute if predicate` 脱离实体即可判定。

## 三、v2 架构

```
L0 钩子   tags/function/{load,tick}
L1 调度   nats:main             $period 节流 + $enable 闸门 + at @r
L2 闸门   nats:check            128 格计数 → $k 次 repeat
L3 随机   nats:rng/step         glibc LCG 保留（3 条计分板指令）；
                                nats:rng/seed → /random value（无实体）
L4 定位   nats:place            ★ 1 个宏文件取代 63 文件二分树
             $execute rotated $(yaw) $(pitch) positioned ^ ^ ^$(dist)
                      align xyz positioned ~.5 ~ ~.5 run function nats:try
L5 判定   nats:try / nats:fall / nats:ground/check     全部纯逻辑，无实体
L6 派发   nats:dispatch         execute if predicate nats:<biome> run function nats:mob/<biome>
L7 内容   nats:mob/<biome> ×18  刷怪表（NBT 规范化由转换器负责）
数据      predicate/<biome> ×17（location_check 版）+ dark.json + tags/block/{solid,free}
```

### 距离映射的算术化（替代 63 文件）

原二分树把 `$s∈[0,31]` 映射到 `27 + 3·$s`（27…120，步长 3）。v2 直接算：

```mcfunction
# nats:do
function nats:rng/step
scoreboard players operation $s nats.rng %= #32 nats.rng
# dist = 27 + 3*s  →  storage nats:macros
scoreboard players operation $dist nats.rng = $s nats.rng
scoreboard players operation $dist nats.rng *= #3 nats.rng
scoreboard players add $dist nats.rng 27
...
function nats:place with storage nats:macros
```

**等价性**：原树是严格二分，叶值 = `27 + 3·(s 的 5 位二进制值)`，与算术式**逐点相等**（已在核验中列出 32 个叶值：27,30,…,120）。

## 四、优化选项（分级，可独立开关）

| 级别 | 项 | 收益 | 风险 |
|---|---|---|---|
| **O1 必做** | 消灭 E1–E4，删 `forceload` 与 30M 依赖 | 移除全部假实体；去掉远区块常驻；`pos_search` 63→1 文件 | 低（宏/谓词语义已取证） |
| **O2 必做** | 17 个生物群系谓词 `entity_properties`→`location_check` | 派发链 4 层 → 1 层 | 低（`LocationCheck` 用 ORIGIN） |
| **O3 推荐** | 修 `basalt_deltas` 悬空引用、RNG 区间重叠、补 `$enable` 写入点 | 恢复丢失的刷怪表 | 低 |
| **O4 可选** | 用 `/random roll <权重…>` 替代 `execute if score $rng matches a..b` 链 | 每张表少 2–4 条指令 | 中（改变 RNG 序列，需重标定） |
| **O5 可选** | 把 18 张表的公共 NBT 抽成宏参数 | 去重，体积下降 | 中（可读性下降） |
| **O6 可选** | `locator_bar_icon` 给自定义怪加定位条图标 | 玩法增强 | 低（非等价改动，默认关） |

**推荐**：O1+O2+O3 做进 `optimized/`；O4/O5/O6 作为开关，默认关，保持与 `original` 行为可比。

## 五、静默计算与实例化验证

### 5.1 实例化（instantiate）
`tools/port.mjs` 与 `tools/optimize.mjs` 真实产出两套数据包：

```
ported/suso.nats/      忠实 1.21.6 移植（结构不变，仅修语法/NBT）
optimized/suso.nats/   v2（O1+O2+O3）
```

### 5.2 静默计算（headless simulation）
`tools/sim.mjs`：一个**不启动游戏**的命令解释器 + 合成世界，直接执行数据包的真实 `.mcfunction` 源码。

- **世界模型**：可配置的地面高度 / 生物群系 / 光照；方块标签查询走真实 `solid.json`/`free.json`。
- **解释器覆盖**：`scoreboard`（add/set/remove/operation/get/reset）、`execute`（`as/at/positioned/rotated/align/if/unless/store/run` 全链）、`function`（含 `with` 宏）、`summon`、`data`、`kill`、`forceload`、`fill`、`random`。
- **选择器**：`@s/@a/@r/@e` + `type/tag/distance/gamemode/predicate/x,y,z,dx,dy,dz/limit/sort`。
- **产出**：逐次尝试的 `(位置, 朝向, 距离, 生物群系, 选中怪)` 事件流。

### 5.3 判据
| 判据 | 方法 |
|---|---|
| 无未知引用 | 解释器遇到未定义 `function`/标签/谓词即报错并计数 = 0 |
| 确定性终止 | 单 tick 指令预算上限 + 递归深度上限，无超限 |
| 距离分布 | 32 个桶各命中 ≈ 1/32，取值 ⊆ {27,30,…,120} |
| **行为等价** | `original`（按 1.20.1 结构）与 `optimized` 在同一世界/同一种子下的事件流**逐条比对**；O1/O2 应完全一致 |
| NBT 正确性 | `verify.mjs` 静态检查：无 `HandItems`/`ArmorItems`/`Attributes:`/`ActiveEffects`/`Count:`/`tag:`/`generic.` 残留，无 `functions/` 等旧路径，`pack_format=80` |
| 方块 ID 合法 | 全部 ∈ `_work/ref/blocks-1.21.6.txt`（1107 项） |

### 5.4 最终实测（可选，需用户）
`/tick freeze` + `/tick sprint 1000` 可在数秒内观察 1000 tick 的刷怪结果；`/tick rate` 可加速。这是 1.20.3 带来的**验证红利**，比等真实时间快 50 倍。

## 六、诚实边界

1. 模拟器是**我方实现**，用于验证**控制流/随机/定位/派发**的等价性与自洽性；它**不能**证明真实 1.21.6 的 NBT 编解码器接受改写后的字段——那只能进游戏验（P1 项）。
2. `location_check` 优先使用 `ORIGIN` 是原版既定语义，本方案据此设计；仍列入进游戏后的首个验证点。
3. `/random roll` 会改变 RNG 序列，故 O4 默认关闭，以保证与 `original` 可比。
