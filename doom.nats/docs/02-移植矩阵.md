# suso.nats → Minecraft 1.21.6 移植矩阵

- **源**：Minecraft 1.20.1（`pack_format` 声明 13）
- **目标**：Minecraft 1.21.6（**data `pack_format` = 80**，resource 63，world_version 4435，protocol 771）
- **目标实例**：`C:\minecraft\Release 2.8.3.zip\.minecraft\versions\1.21.6-Fabric 0.16.14`（另有 0.16.16）
- **取证基准**：`1.21.6-Fabric 0.16.14.jar`（Fabric 版即打过补丁的客户端 jar，含 1107 个方块与完整 `data/minecraft` 原版数据包）
- **取证方法**：class 文件常量池 `CONSTANT_String` 精确抽取 + 父类/接口判定
  （`com/mojang/datafixers/DataFix` = **仅世界升级 fixer，命令期无效**；引用 `com/mojang/serialization` = **编解码器，命令期有效**）

---

## A. 阻塞级（不改则整包失效）

| # | 位置 | 1.20.1 写法 | 1.21.6 要求 | 证据 | 影响面 |
|---|---|---|---|---|---|
| **A1** | 全部目录 | `data/<ns>/functions/`<br>`data/<ns>/predicates/`<br>`data/<ns>/tags/blocks/`<br>`data/minecraft/tags/functions/` | `data/<ns>/function/`<br>`data/<ns>/predicate/`<br>`data/<ns>/tags/block/`<br>`data/minecraft/tags/function/` | jar 内原版标签目录实测为**单数**：`block, entity_type, item, game_event, enchantment, dialog, banner_pattern, worldgen, …`，**不存在 `blocks`/`functions`** | 125 文件全部需改路径 |
| **A2** | `tags/block/free.json` | `"minecraft:grass"` | `"minecraft:short_grass"` | 1.21.6 方块表 1107 项中**无 `grass`**，含 grass 的仅 `grass_block, short_grass, tall_grass, seagrass, tall_seagrass, short_dry_grass, tall_dry_grass`；`grass` 于 1.20.3 更名 | **致命**：标签整文件加载失败 → `#suso.nats:free` 不存在 → `execute if block … #suso.nats:free` 解析失败 → `spawn/float/check`、`spawn/ground/check` 报废（1.20.2 起函数在**加载期**解析，错误即失效） |
| **A3** | `ns_ground_dark.mcfunction` | `function suso.nats:spawn/ground/basalt_deltas` | `…ground/dark_basalt_deltas` | 目录内实际文件为 `dark_basalt_deltas.mcfunction`，**无** `basalt_deltas.mcfunction` | 1.20.1 为运行期报错；1.21.6 起**加载期**解析，该函数整体失效 → 全部暗侧地面刷怪中断 |
| **A4** | `pack.mcmeta` | `"pack_format": 13` | `"pack_format": 80`（可选 `supported_formats`） | jar `version.json` → `pack_version.data = 80` | 仅告警不阻断（可后置） |

> **结论**：A1+A2+A3 是"不改必死"三项。其中 **A2 最隐蔽**——它不会报"缺少方块"，而是让 `free` 标签静默消失，进而让两条 `check` 函数失效，表现为"怪物完全不刷"。

## B. 功能级（能加载，但行为错误 — NBT 体系重写）

1.21.6 的实体 NBT 仍**大量沿用 CamelCase**（`Tags` `Health` `Silent` `Glowing` `Invulnerable` `NoGravity` `CanPickUpLoot` `IsBaby` `NoAI` `PersistenceRequired` `Fuse` `AngerTime` `Team` `CustomName` `CustomNameVisible` `UUID` `powered` `VillagerData` 等一律保留），
但**四组结构被替换**，且旧写法**只存在于 DataFixer，命令期无效**：

| # | 字段 | 1.20.1 写法 | 1.21.6 写法 | 证据（jar 字符串常量） |
|---|---|---|---|---|
| **B1** | 手持/护甲 | `HandItems:[…]`<br>`ArmorItems:[…]` | `equipment:{mainhand:…, offhand:…, head:…, chest:…, legs:…, feet:…, body:…}` | `HandItems` 仅见于 fixer `bgx,bid,bnn`；`hand_items` **全 jar 0 次**；运行时 `equipment` 见于 `cam,eaw,bz,…` |
| **B2** | 掉落率 | `HandDropChances:[…]`<br>`ArmorDropChances:[…]` | `drop_chances:{mainhand:…,…}` | `HandDropChances`/`ArmorDropChances` 仅 fixer；`hand_drop_chances` **0 次**；`drop_chances` 见于 `cao,eaw` |
| **B3** | 属性 | `Attributes:[{Name:"generic.max_health",Base:28}]` | `attributes:[{id:"minecraft:max_health",base:28.0}]` | 运行时 `cam` 用 `attributes`；`Attributes` 仅 fixer `beh,bej` |
| **B4** | 状态效果 | `ActiveEffects:[{Id:5,Amplifier:0b,Duration:-1,ShowParticles:1b}]` | `active_effects:[{id:"minecraft:strength",amplifier:0,duration:-1,show_particles:true}]` | `ActiveEffects` 仅 fixer `bgm,bkg`；运行时 `cam` 用 `active_effects`；`Id/Amplifier/Duration/ShowParticles` 均为 fixer-only，`amplifier/duration/show_particles` 为运行时 |
| **B5** | 物品栈 | `{id:"minecraft:bow",Count:1b,tag:{…}}` | `{id:"minecraft:bow",count:1,components:{…}}` | `btag/Count` 的**唯一**同现类是 fixer `bjf$a`（`ItemStackComponentizationFix`，继承 `DataFix`）；运行时 `count`/`components` 见于 `dip,dlo,dcn` |
| **B6** | 文本组件 | `CustomName:'{"text":"Rage Creeper","color":"red"}'` | `CustomName:{text:"Rage Creeper",color:"red"}` | 1.21.5 起组件改 SNBT；JSON 字符串会被当作**纯文本原样显示** |

### B5 展开：`tag` → `components` 逐条映射

| 旧（`tag` 内） | 新（`components` 内） | 备注 |
|---|---|---|
| `Enchantments:[{id:"minecraft:power",lvl:1s}]` | `enchantments:{"minecraft:power":1}` | 键=附魔 ID，值=等级 |
| `CustomModelData:42` | `custom_model_data:42` | |
| `display:{color:2768953}` | `dyed_color:2768953` | 皮革染色 |
| `Trim:{material:"minecraft:lapis",pattern:"minecraft:shaper"}` | `trim:{material:"minecraft:lapis",pattern:"minecraft:shaper"}` | 由 `tag` 移到 `components`（`trim` 组件） |
| `AttributeModifiers:[{AttributeName:"generic.attack_damage",Name:"…",Amount:12,Operation:0,UUID:[I;…],Slot:"mainhand"}]` | `attribute_modifiers:[{type:"minecraft:attack_damage",id:"…",amount:12,operation:"add_value",slot:"mainhand"}]` | `Operation` 数字→字串枚举：`0→add_value`、`1→add_multiplied_base`、`2→add_multiplied_total` |
| `SkullOwner:{Id:[I;…],Properties:{textures:[{Value:"…"}]}}` | `profile:{id:[I;…],properties:[{name:"textures",value:"…"}]}` | 玩家头颅贴图 |

### B3 展开：属性名清理（1.21.2 起去掉 `generic.` 前缀）

| 1.20.1 | 1.21.6 |
|---|---|
| `generic.max_health` | `max_health` |
| `generic.follow_range` | `follow_range` |
| `generic.movement_speed` | `movement_speed` |
| `generic.attack_damage` | `attack_damage` |
| `generic.attack_knockback` | `attack_knockback` |
| `generic.knockback_resistance` | `knockback_resistance` |

### B4 展开：数字效果 ID → 字串 ID（本包实际用到）

| 数字 | 1.21.6 字串 | 出现处 |
|---|---|---|
| 5 | `minecraft:strength` | `dark_desert`（husk） |
| 12 | `minecraft:fire_resistance` | `dark_desert`（rage creeper） |
| 14 | `minecraft:invisibility` | `dark_the_void`、`dark_basalt_deltas` |
| 15 | `minecraft:blindness` | `dark_forest`（nightmare） |
| 33 | `minecraft:slowness` | `dark_snowy_taiga`（frigid creeper） |

> **B1/B2 影响面最大**：23 处 `HandItems` + 9 处 `ArmorItems` + 32 处掉落率 + **34 处 `Attributes`** + 13 处 `ActiveEffects` + 21 处 `CustomName`。
> 不改则**所有自定义怪物赤手空拳、无护甲、血量/伤害/移速全部回到默认值、无状态效果**——即整张地图的难度设计归零。
> 具体待重写的物品 NBT：47 处 `Count:` / 38 处 `tag:` / 12 处 `Enchantments` / 12 处 `Trim` / 11 处 `display:` / 8 处 `CustomModelData` / 8 处 `SkullOwner` / 3 处 `AttributeModifiers`。
> 全包共 **82 处 `summon`**，涉及 21 种实体类型。

## C. 语义待确认项（jar 无法离线定论，需实测）

| # | 项 | 现状 | 风险 | 处置 |
|---|---|---|---|---|
| **C1** | `DeathLootTable:"none"` | `dark_the_void` 的 vermoid 用此关闭掉落 | `DeathLootTable` 未在运行时编解码器检出（仅 fixer 痕迹）；若失效则该怪掉默认战利品 | 改为 `minecraft:empty` 或改走 `drop_chances:0` + `armor_items` 空 |
| **C2** | `CustomName` JSON→SNBT | 19 处 | 若不改，怪物头顶显示 `{"text":"Rage Creeper",…}` 原始 JSON | 统一改 SNBT；SNBT 形式在 1.20.1 与 1.21.6 **双向可用**，无风险 |
| **C3** | UUID 宽松解析 `50502711-0-0-4-0` | `data modify entity <uuid> Rotation` | 若 1.21.6 收紧为严格 UUID 字串，则该选择器失配 → 定位层全废 | 改为标准形式 `50502711-0000-0000-0004-000000000000`，两版通用 |
| **C4** | `forceload add 29999999 27115050` | 哨兵区块保活 | 1.21.6 坐标上限仍为 ±30,000,000，`29999999` 在界内（推断安全） | 实测确认 |
| **C5** | 生物群系谓词 | 17 个 `entity_properties → location.biome` | 1.21.6 生物群系注册表 65 项，17 个引用**全部存在** ✅ | 无需改动 |
| **C6** | `dark.json` 亮度谓词 | `location_check → light.light: 0..3` | 已确认 1.21.6 仍有 `location_check` / `entity_properties`（`fgu`）与 `light` 字段（`cs` = `LightPredicate{light}`） ✅ | 无需改动 |
| **C7** | `suso.rng` 是否被引用 | `suso.nats` 自带 LCG | 否 | 无需改动 |

## D. 优化项（移植同时可做）

| # | 优化 | 收益 | 风险 |

## E. 建议的产物布局

```
doom.nats/
├── original/suso.nats/       1.20.1 原样副本（已就位，125 文件）
├── ported/suso.nats/         1.21.6 产物（pack_format 80）
│   ├── pack.mcmeta
│   └── data/{minecraft,suso.nats}/{function,predicate,tags/{block,function}}
├── tools/                    转换器（Node.js，可重复运行）
│   ├── lib/snbt.mjs          SNBT 词法/语法
│   ├── rules/nbt-1.21.mjs    实体/物品 NBT 重写规则
│   └── port.mjs              original → ported
└── docs/
```

**推荐方案：转换器（可重复）而非手工改包** —— 理由：改动点 400+ 且高度规则化，手工改易漏；转换器可版本化、可回归、可复用于上游更新。
